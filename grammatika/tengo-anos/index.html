A0 Самое начало уровень · 104 упражнений

Правило коротко

Возраст говорят через tengo / tienes / tiene + число + años: Tengo diez años (мне десять лет), ¿Cuántos años tienes? (сколько тебе лет?), Ana tiene ocho años (Ане восемь лет). Вежливо: ¿Cuántos años tiene usted? (сколько вам лет?). Один год — un año.
