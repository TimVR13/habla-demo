Как пишется слово: буквы по-испански в испанском

A0 Самое начало уровень · 106 упражнений

Отвечает на вопросы: Как называются буквы h, j, ñ, v, z? · Как спросить, с b или с v пишется слово? · Как продиктовать адрес электронной почты?

Правило коротко

Спросить: ¿Cómo se escribe? (как это пишется?), ¿Cómo se escribe tu apellido? (как пишется твоя фамилия?). Ответ по буквам: ge, o, eme, e, zeta (Gómez). Особые буквы: h — hache, j — jota, g — ge, ñ — eñe, v — uve, z — zeta; @ — arroba, точка — punto. С большой буквы (con mayúscula) — имена и страны, с маленькой (con minúscula) — национальности и языки: español.

Упражнения с ответами

Вставьте пропущенное слово, затем откройте ответ.

  1. La letra «h» se llama _____. (hache / jota / ge / ce)
    ОтветLa letra «h» se llama hache. — Буква «h» называется «аче».
  2. La letra «j» se llama _____. (jota / ge / hache / ka)
    ОтветLa letra «j» se llama jota. — Буква «j» называется «хота».
  3. La letra «ñ» se llama _____. (eñe / ene / eme / ele)
    ОтветLa letra «ñ» se llama eñe. — Буква «ñ» называется «энье».
  4. La letra «v» se llama _____. (uve / be / efe / u)
    ОтветLa letra «v» se llama uve. — Буква «v» называется «убэ».
  5. La letra «b» se llama _____. (be / uve / pe / de)
    ОтветLa letra «b» se llama be. — Буква «b» называется «бэ».
  6. — ¿Cómo se escribe «Bogotá»? — Con _____, no con uve. (be / uve / pe / de)
    Ответ— ¿Cómo se escribe «Bogotá»? — Con be, no con uve. — — Как пишется «Богота»? — С b, а не с v.
  7. — ¿Cómo se escribe «Valencia»? — Con _____, no con be. (uve / be / efe / u)
    Ответ— ¿Cómo se escribe «Valencia»? — Con uve, no con be. — — Как пишется «Валенсия»? — С v, а не с b.
  8. «Honduras» se escribe con _____ al principio. (hache / jota / ge / o)
    Ответ«Honduras» se escribe con hache al principio. — «Гондурас» пишется с h в начале.
  9. «Hotel» se escribe con _____, pero no se lee. (hache / jota / ge / o)
    Ответ«Hotel» se escribe con hache, pero no se lee. — «Hotel» пишется с h, но она не читается.
  10. «España» se escribe con _____. (eñe / ene / eme / ele)
    Ответ«España» se escribe con eñe. — «Испания» пишется с ñ.
  11. — ¿«Bilbao» se escribe con be o con uve? — Con _____. (be / uve / pe / efe)
    Ответ— ¿«Bilbao» se escribe con be o con uve? — Con be. — — «Бильбао» пишется с b или с v? — С b.
  12. — ¿«Vicente» se escribe con be o con uve? — Con _____. (uve / be / efe / u)
    Ответ— ¿«Vicente» se escribe con be o con uve? — Con uve. — — «Висенте» пишется с b или с v? — С v.
  13. «Jorge» se escribe con jota al principio y con _____ al final. (ge / jota / hache / erre)
    Ответ«Jorge» se escribe con jota al principio y con ge al final. — «Хорхе» пишется с j в начале и с g в конце.
  14. «Gijón» se escribe con ge y con _____. (jota / ge / hache / i)
    Ответ«Gijón» se escribe con ge y con jota. — «Хихон» пишется с g и с j.
  15. «Hola»: _____, o, ele, a. (hache / jota / ge / o)
    Ответ«Hola»: hache, o, ele, a. — «Hola»: «аче», «о», «эле», «а».
