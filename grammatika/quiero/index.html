Я хочу… Сколько стоит? в испанском

A0 Самое начало уровень · 101 упражнений

Отвечает на вопросы: Как вежливо заказать в кафе? · Когда cuesta, а когда cuestan? · Как сказать «мне чай»?

Правило коротко

Quiero un café (я хочу кофе), ¿Quieres un té? (хочешь чаю?), Ana quiere una pizza (Ана хочет пиццу). Вежливо — quisiera: Quisiera una mesa para dos (я бы хотел столик на двоих). Мне — para mí. Цена: ¿Cuánto cuesta? — для одной вещи, ¿Cuánto cuestan? — для нескольких: Cuesta dos euros (стоит два евро). Счёт — la cuenta, por favor.

Упражнения с ответами

Вставьте пропущенное слово, затем откройте ответ.

  1. _____ un café. (Quiero / Quieres / Quiere / Soy)
    ОтветQuiero un café. — Я хочу кофе.
  2. ¿_____ un té? (Quieres / Quiero / Quiere / Eres)
    Ответ¿Quieres un té? — Хочешь чаю?
  3. Ana _____ una pizza. (quiere / quiero / quieres / es)
    ОтветAna quiere una pizza. — Ана хочет пиццу.
  4. Quiero _____ cerveza. (una / un / uno)
    ОтветQuiero una cerveza. — Я хочу пиво.
  5. Quiero _____ helado. (un / una / uno)
    ОтветQuiero un helado. — Я хочу мороженое.
  6. — ¿Qué quiere usted? — _____ un café con leche, por favor. (Quiero / Quiere / Quieres / Soy)
    Ответ— ¿Qué quiere usted? — Quiero un café con leche, por favor. — — Что вы будете? — Хочу кофе с молоком, пожалуйста.
  7. — Buenos días, ¿qué quiere usted? — Para _____, un té, y para él, un café. (mí / mi / yo / me)
    Ответ— Buenos días, ¿qué quiere usted? — Para mí, un té, y para él, un café. — — Доброе утро, что вы будете? — Мне чай, а ему кофе.
  8. — ¿Y para usted, señora? — Para mí, _____ ensalada, por favor. (una / un / uno)
    Ответ— ¿Y para usted, señora? — Para mí, una ensalada, por favor. — — А вам, сеньора? — Мне салат, пожалуйста.
  9. — Hola, ¿qué tal? ¿Quieres un helado? — Sí, ¡muchas _____! (gracias / nada / favor / permiso)
    Ответ— Hola, ¿qué tal? ¿Quieres un helado? — Sí, ¡muchas gracias! — — Привет, как дела? Хочешь мороженое? — Да, большое спасибо!
  10. — Perdone, ¿cuánto cuesta la pizza? — _____ doce euros. (Cuesta / Cuestan / Cuenta / Cuestas)
    Ответ— Perdone, ¿cuánto cuesta la pizza? — Cuesta doce euros. — — Простите, сколько стоит пицца? — Двенадцать евро.
  11. _____ un café, por favor. (Quisiera / Quieres / Quiere / Cuesta)
    ОтветQuisiera un café, por favor. — Я бы хотел кофе, пожалуйста.
  12. Para _____, un agua. (mí / mi / yo / me)
    ОтветPara mí, un agua. — Мне воды.
  13. ¿Cuánto _____ los helados? (cuestan / cuesta / cuentan / cuestas)
    Ответ¿Cuánto cuestan los helados? — Сколько стоят мороженые?
  14. ¿Cuánto _____ la cerveza? (cuesta / cuestan / cuenta / cuestas)
    Ответ¿Cuánto cuesta la cerveza? — Сколько стоит пиво?
  15. Quiero _____ mapa de Sevilla. (un / una / uno)
    ОтветQuiero un mapa de Sevilla. — Я хочу карту Севильи.
