Спряжение глагола temer

temer — бояться. Правильный глагол, уровень B1.

Настоящее (presente de indicativo)

yotemo
tútemes
él / ella / ustedteme
nosotrostememos
vosotrosteméis
ellos / ustedestemen

Прошедшее законченное (pretérito indefinido)

yotemí
tútemiste
él / ella / ustedtemió
nosotrostemimos
vosotrostemisteis
ellos / ustedestemieron

Прошедшее длительное (pretérito imperfecto)

yotemía
tútemías
él / ella / ustedtemía
nosotrostemíamos
vosotrostemíais
ellos / ustedestemían

Будущее (futuro simple)

yotemeré
tútemerás
él / ella / ustedtemerá
nosotrostemeremos
vosotrostemeréis
ellos / ustedestemerán

Условное (condicional simple)

yotemería
tútemerías
él / ella / ustedtemería
nosotrostemeríamos
vosotrostemeríais
ellos / ustedestemerían

Повелительное (imperativo afirmativo)

túteme
ustedtema
nosotrostemamos
vosotrostemed
ustedesteman

Subjuntivo настоящее (presente de subjuntivo)

yotema
tútemas
él / ella / ustedtema
nosotrostemamos
vosotrostemáis
ellos / ustedesteman

Subjuntivo прошедшее (imperfecto de subjuntivo (-ra))

yotemiera
tútemieras
él / ella / ustedtemiera
nosotrostemiéramos
vosotrostemierais
ellos / ustedestemieran
