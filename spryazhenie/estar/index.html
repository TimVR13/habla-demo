Спряжение глагола estar

estar — быть, находиться. Неправильный глагол, уровень A1. yo: estoy; прош.: estuve; ударение: está, esté.

Настоящее (presente de indicativo)

yoestoy
túestás
él / ella / ustedestá
nosotrosestamos
vosotrosestáis
ellos / ustedesestán

Прошедшее законченное (pretérito indefinido)

yoestuve
túestuviste
él / ella / ustedestuvo
nosotrosestuvimos
vosotrosestuvisteis
ellos / ustedesestuvieron

Прошедшее длительное (pretérito imperfecto)

yoestaba
túestabas
él / ella / ustedestaba
nosotrosestábamos
vosotrosestabais
ellos / ustedesestaban

Будущее (futuro simple)

yoestaré
túestarás
él / ella / ustedestará
nosotrosestaremos
vosotrosestaréis
ellos / ustedesestarán

Условное (condicional simple)

yoestaría
túestarías
él / ella / ustedestaría
nosotrosestaríamos
vosotrosestaríais
ellos / ustedesestarían

Повелительное (imperativo afirmativo)

túestá
ustedesté
nosotrosestemos
vosotrosestad
ustedesestén

Subjuntivo настоящее (presente de subjuntivo)

yoesté
túestés
él / ella / ustedesté
nosotrosestemos
vosotrosestéis
ellos / ustedesestén

Subjuntivo прошедшее (imperfecto de subjuntivo (-ra))

yoestuviera
túestuvieras
él / ella / ustedestuviera
nosotrosestuviéramos
vosotrosestuvierais
ellos / ustedesestuvieran
