Спряжение глагола existir

existir — существовать. Правильный глагол, уровень B1.

Настоящее (presente de indicativo)

yoexisto
túexistes
él / ella / ustedexiste
nosotrosexistimos
vosotrosexistís
ellos / ustedesexisten

Прошедшее законченное (pretérito indefinido)

yoexistí
túexististe
él / ella / ustedexistió
nosotrosexistimos
vosotrosexististeis
ellos / ustedesexistieron

Прошедшее длительное (pretérito imperfecto)

yoexistía
túexistías
él / ella / ustedexistía
nosotrosexistíamos
vosotrosexistíais
ellos / ustedesexistían

Будущее (futuro simple)

yoexistiré
túexistirás
él / ella / ustedexistirá
nosotrosexistiremos
vosotrosexistiréis
ellos / ustedesexistirán

Условное (condicional simple)

yoexistiría
túexistirías
él / ella / ustedexistiría
nosotrosexistiríamos
vosotrosexistiríais
ellos / ustedesexistirían

Повелительное (imperativo afirmativo)

túexiste
ustedexista
nosotrosexistamos
vosotrosexistid
ustedesexistan

Subjuntivo настоящее (presente de subjuntivo)

yoexista
túexistas
él / ella / ustedexista
nosotrosexistamos
vosotrosexistáis
ellos / ustedesexistan

Subjuntivo прошедшее (imperfecto de subjuntivo (-ra))

yoexistiera
túexistieras
él / ella / ustedexistiera
nosotrosexistiéramos
vosotrosexistierais
ellos / ustedesexistieran

Примеры с глаголом existir

La tienda cerró hace un año; ya no existe.
Магазин закрылся год назад: его больше нет.
Ese árbol bajo el que nos sentábamos de niños ya no existe.
Того дерева, под которым мы сидели в детстве, больше нет.
No existe ninguna medicina que lo cure todo.
Не существует лекарства, которое лечило бы всё.
