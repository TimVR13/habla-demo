Спряжение глагола firmar

firmar — подписывать. Правильный глагол, уровень B1.

Настоящее (presente de indicativo)

yofirmo
túfirmas
él / ella / ustedfirma
nosotrosfirmamos
vosotrosfirmáis
ellos / ustedesfirman

Прошедшее законченное (pretérito indefinido)

yofirmé
túfirmaste
él / ella / ustedfirmó
nosotrosfirmamos
vosotrosfirmasteis
ellos / ustedesfirmaron

Прошедшее длительное (pretérito imperfecto)

yofirmaba
túfirmabas
él / ella / ustedfirmaba
nosotrosfirmábamos
vosotrosfirmabais
ellos / ustedesfirmaban

Будущее (futuro simple)

yofirmaré
túfirmarás
él / ella / ustedfirmará
nosotrosfirmaremos
vosotrosfirmaréis
ellos / ustedesfirmarán

Условное (condicional simple)

yofirmaría
túfirmarías
él / ella / ustedfirmaría
nosotrosfirmaríamos
vosotrosfirmaríais
ellos / ustedesfirmarían

Повелительное (imperativo afirmativo)

túfirma
ustedfirme
nosotrosfirmemos
vosotrosfirmad
ustedesfirmen

Subjuntivo настоящее (presente de subjuntivo)

yofirme
túfirmes
él / ella / ustedfirme
nosotrosfirmemos
vosotrosfirméis
ellos / ustedesfirmen

Subjuntivo прошедшее (imperfecto de subjuntivo (-ra))

yofirmara
túfirmaras
él / ella / ustedfirmara
nosotrosfirmáramos
vosotrosfirmarais
ellos / ustedesfirmaran

No firmes hasta que leas el contrato.
Не подписывай, пока не прочтёшь договор.
Tan pronto como firmes el contrato, empezarás a trabajar.
Как только подпишешь договор, начнёшь работать.
Señor, no firme esos documentos sin leerlos antes.
Сеньор, не подписывайте эти документы, не прочитав их.
¿Me firmas este papel? — Sí, ahora te lo firmo.
Подпишешь мне эту бумагу? — Да, сейчас подпишу.

Ручка, которой я подписал договор, была папиной.
Es necesario que usted firme este formulario.
Нужно, чтобы вы подписали эту форму.
Les enviamos el contrato a fin de que lo firmen antes del viernes.
Направляем вам договор, чтобы вы подписали его до пятницы.
