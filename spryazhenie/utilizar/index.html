Спряжение глагола utilizar

utilizar — использовать. Правильный глагол, уровень B1. z → c перед e: utilicé, utilice.

Настоящее (presente de indicativo)

youtilizo
túutilizas
él / ella / ustedutiliza
nosotrosutilizamos
vosotrosutilizáis
ellos / ustedesutilizan

Прошедшее законченное (pretérito indefinido)

youtilicé
túutilizaste
él / ella / ustedutilizó
nosotrosutilizamos
vosotrosutilizasteis
ellos / ustedesutilizaron

youtilizaba
túutilizabas
él / ella / ustedutilizaba
nosotrosutilizábamos
vosotrosutilizabais
ellos / ustedesutilizaban

túutilizarás

nosotrosutilizaremos

ellos / ustedesutilizarán

Условное (condicional simple)

youtilizaría
túutilizarías
él / ella / ustedutilizaría
nosotrosutilizaríamos
vosotrosutilizaríais
ellos / ustedesutilizarían

Повелительное (imperativo afirmativo)

ustedutilice

ustedesutilicen
