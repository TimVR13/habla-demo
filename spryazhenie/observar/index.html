Спряжение глагола observar

observar — наблюдать. Правильный глагол, уровень B1.

Настоящее (presente de indicativo)

yoobservo
túobservas
él / ella / ustedobserva
nosotrosobservamos
vosotrosobserváis
ellos / ustedesobservan

Прошедшее законченное (pretérito indefinido)

yoobservé
túobservaste
él / ella / ustedobservó
nosotrosobservamos
vosotrosobservasteis
ellos / ustedesobservaron

Прошедшее длительное (pretérito imperfecto)

yoobservaba
túobservabas
él / ella / ustedobservaba
nosotrosobservábamos
vosotrosobservabais
ellos / ustedesobservaban

Будущее (futuro simple)

yoobservaré
túobservarás
él / ella / ustedobservará
nosotrosobservaremos
vosotrosobservaréis
ellos / ustedesobservarán

Условное (condicional simple)

yoobservaría
túobservarías
él / ella / ustedobservaría
nosotrosobservaríamos
vosotrosobservaríais
ellos / ustedesobservarían

Повелительное (imperativo afirmativo)

túobserva
ustedobserve
nosotrosobservemos
vosotrosobservad
ustedesobserven

Subjuntivo настоящее (presente de subjuntivo)

yoobserve
túobserves
él / ella / ustedobserve
nosotrosobservemos
vosotrosobservéis
ellos / ustedesobserven

Subjuntivo прошедшее (imperfecto de subjuntivo (-ra))

yoobservara
túobservaras
él / ella / ustedobservara
nosotrosobserváramos
vosotrosobservarais
ellos / ustedesobservaran

Примеры с глаголом observar

Siento que alguien me observa desde la ventana.
Я чувствую, что кто-то наблюдает за мной из окна.
