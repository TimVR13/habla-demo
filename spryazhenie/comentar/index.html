Спряжение глагола comentar

comentar — комментировать. Правильный глагол, уровень B1.

Настоящее (presente de indicativo)

yocomento
túcomentas
él / ella / ustedcomenta
nosotroscomentamos
vosotroscomentáis
ellos / ustedescomentan

Прошедшее законченное (pretérito indefinido)

yocomenté
túcomentaste
él / ella / ustedcomentó
nosotroscomentamos
vosotroscomentasteis
ellos / ustedescomentaron

Прошедшее длительное (pretérito imperfecto)

yocomentaba
túcomentabas
él / ella / ustedcomentaba
nosotroscomentábamos
vosotroscomentabais
ellos / ustedescomentaban

Будущее (futuro simple)

yocomentaré
túcomentarás
él / ella / ustedcomentará
nosotroscomentaremos
vosotroscomentaréis
ellos / ustedescomentarán

Условное (condicional simple)

yocomentaría
túcomentarías
él / ella / ustedcomentaría
nosotroscomentaríamos
vosotroscomentaríais
ellos / ustedescomentarían

Повелительное (imperativo afirmativo)

túcomenta
ustedcomente
nosotroscomentemos
vosotroscomentad
ustedescomenten

Subjuntivo настоящее (presente de subjuntivo)

yocomente
túcomentes
él / ella / ustedcomente
nosotroscomentemos
vosotroscomentéis
ellos / ustedescomenten

yocomentara
túcomentaras
él / ella / ustedcomentara
nosotroscomentáramos
vosotroscomentarais
ellos / ustedescomentaran

Примеры с глаголом comentar

Se comenta que la reunión se aplazará hasta junio.
Поговаривают, что собрание перенесут на июнь.
«Me gustaría estudiar en Chile». → Pedro comentó que le gustaría estudiar en Chile.
«Я бы хотел учиться в Чили». → Педро сказал, что хотел бы учиться в Чили.
Comentan que el nuevo restaurante es buenísimo.
Говорят, новый ресторан просто отличный.
