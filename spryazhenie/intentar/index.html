Спряжение глагола intentar

intentar — пытаться. Правильный глагол, уровень A2.

Настоящее (presente de indicativo)

yointento
túintentas
él / ella / ustedintenta
nosotrosintentamos
vosotrosintentáis
ellos / ustedesintentan

Прошедшее законченное (pretérito indefinido)

yointenté
túintentaste
él / ella / ustedintentó
nosotrosintentamos
vosotrosintentasteis
ellos / ustedesintentaron

Прошедшее длительное (pretérito imperfecto)

yointentaba
túintentabas
él / ella / ustedintentaba
nosotrosintentábamos
vosotrosintentabais
ellos / ustedesintentaban

yointentaré
túintentarás
él / ella / ustedintentará
nosotrosintentaremos
vosotrosintentaréis
ellos / ustedesintentarán

Условное (condicional simple)

yointentaría
túintentarías
él / ella / ustedintentaría
nosotrosintentaríamos
vosotrosintentaríais
ellos / ustedesintentarían

Повелительное (imperativo afirmativo)

túintenta
ustedintente
nosotrosintentemos
vosotrosintentad
ustedesintenten

Subjuntivo настоящее (presente de subjuntivo)

yointente
túintentes
él / ella / ustedintente
nosotrosintentemos

Примеры с глаголом intentar

Intenté abrir la puerta, pero no pude.
Я пытался открыть дверь, но не смог.
