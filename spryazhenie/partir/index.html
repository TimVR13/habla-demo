Спряжение глагола partir

partir — отправляться; делить, резать. Правильный глагол, уровень B1.

Настоящее (presente de indicativo)

yoparto
túpartes
él / ella / ustedparte
nosotrospartimos
vosotrospartís
ellos / ustedesparten

Прошедшее законченное (pretérito indefinido)

yopartí
túpartiste
él / ella / ustedpartió
nosotrospartimos
vosotrospartisteis
ellos / ustedespartieron

Прошедшее длительное (pretérito imperfecto)

yopartía
túpartías
él / ella / ustedpartía
nosotrospartíamos
vosotrospartíais
ellos / ustedespartían

yopartiré
túpartirás
él / ella / ustedpartirá
nosotrospartiremos
vosotrospartiréis
ellos / ustedespartirán

yopartiría
túpartirías
él / ella / ustedpartiría
nosotrospartiríamos
vosotrospartiríais
ellos / ustedespartirían

Повелительное (imperativo afirmativo)

túparte
ustedparta
nosotrospartamos
vosotrospartid
ustedespartan
