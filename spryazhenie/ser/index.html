Спряжение глагола ser

ser — быть (кем, каким). Неправильный глагол, уровень A1. полностью неправильный: soy, eres; прош.: fui, fue; imperf.: era.

Настоящее (presente de indicativo)

yosoy
túeres
él / ella / ustedes
nosotrossomos
vosotrossois
ellos / ustedesson

Прошедшее законченное (pretérito indefinido)

yofui
túfuiste
él / ella / ustedfue
nosotrosfuimos
vosotrosfuisteis
ellos / ustedesfueron

Прошедшее длительное (pretérito imperfecto)

yoera
túeras
él / ella / ustedera
nosotroséramos
vosotroserais
ellos / ustedeseran

Будущее (futuro simple)

yoseré
túserás
él / ella / ustedserá
nosotrosseremos
vosotrosseréis
ellos / ustedesserán

Условное (condicional simple)

yosería
túserías
él / ella / ustedsería
nosotrosseríamos
vosotrosseríais
ellos / ustedesserían

Повелительное (imperativo afirmativo)

túsé
ustedsea
nosotrosseamos
vosotrossed
ustedessean

Subjuntivo настоящее (presente de subjuntivo)

yosea
túseas
él / ella / ustedsea
nosotrosseamos
vosotrosseáis
ellos / ustedessean

Subjuntivo прошедшее (imperfecto de subjuntivo (-ra))

yofuera
túfueras
él / ella / ustedfuera
nosotrosfuéramos
vosotrosfuerais
ellos / ustedesfueran

Примеры с глаголом ser

Soy de Argentina.
Я из Аргентины.
Mi madre es profesora.
Моя мама — учительница.
Somos amigos.
Мы друзья.
¿Eres estudiante?
Ты студент?
Ustedes son muy simpáticos.
Вы очень милые.
Son de Argentina.
Они из Аргентины.
Soy médico.
Я врач.
Usted es el señor García, ¿verdad?
Вы сеньор Гарсия, верно?
