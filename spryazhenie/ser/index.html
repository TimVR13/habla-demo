Спряжение глагола ser

ser — быть (кем, каким). Неправильный глагол, уровень A1. полностью неправильный: soy, eres; прош.: fui, fue; imperf.: era.

Настоящее (presente de indicativo)

yosoy
túeres
él / ella / ustedes
nosotrossomos
vosotrossois
ellos / ustedesson

Прошедшее законченное (pretérito indefinido)

yofui
túfuiste
él / ella / ustedfue
nosotrosfuimos
vosotrosfuisteis
ellos / ustedesfueron

yoera
túeras
él / ella / ustedera

vosotroserais
