Спряжение глагола respetar

respetar — уважать. Правильный глагол, уровень B1.

Настоящее (presente de indicativo)

yorespeto
túrespetas
él / ella / ustedrespeta
nosotrosrespetamos
vosotrosrespetáis
ellos / ustedesrespetan

Прошедшее законченное (pretérito indefinido)

yorespeté
túrespetaste
él / ella / ustedrespetó
nosotrosrespetamos
vosotrosrespetasteis
ellos / ustedesrespetaron

Прошедшее длительное (pretérito imperfecto)

yorespetaba
túrespetabas
él / ella / ustedrespetaba
nosotrosrespetábamos
vosotrosrespetabais
ellos / ustedesrespetaban

Будущее (futuro simple)

yorespetaré
túrespetarás
él / ella / ustedrespetará
nosotrosrespetaremos
vosotrosrespetaréis
ellos / ustedesrespetarán

Условное (condicional simple)

yorespetaría
túrespetarías
él / ella / ustedrespetaría
nosotrosrespetaríamos
vosotrosrespetaríais
ellos / ustedesrespetarían

Повелительное (imperativo afirmativo)

túrespeta
ustedrespete
nosotrosrespetemos
vosotrosrespetad
ustedesrespeten

Subjuntivo настоящее (presente de subjuntivo)

yorespete
túrespetes
él / ella / ustedrespete
nosotrosrespetemos
vosotrosrespetéis
ellos / ustedesrespeten

él / ella / ustedrespetara
nosotrosrespetáramos
vosotrosrespetarais
ellos / ustedesrespetaran

Примеры с глаголом respetar

En esta escuela se trata a los alumnos con respeto.
В этой школе к ученикам относятся с уважением.
En este país se respeta a los profesores.
В этой стране уважают учителей.
Siempre y cuando respetes las reglas, puedes participar.
При условии, что ты соблюдаешь правила, можешь участвовать.
