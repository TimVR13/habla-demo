Спряжение глагола quemar

quemar — жечь, сжигать. Правильный глагол, уровень B1.

Настоящее (presente de indicativo)

yoquemo
túquemas
él / ella / ustedquema
nosotrosquemamos
vosotrosquemáis
ellos / ustedesqueman

Прошедшее законченное (pretérito indefinido)

túquemaste
él / ella / ustedquemó
nosotrosquemamos
vosotrosquemasteis
ellos / ustedesquemaron

túquemabas
él / ella / ustedquemaba
nosotrosquemábamos

ellos / ustedesquemarían

Примеры с глаголом quemar

Esa sartén quema: no la toques.
Эта сковорода горячая: не трогай её.
Se te quemó el arroz.
У тебя подгорел рис.
