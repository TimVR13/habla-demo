Спряжение глагола resolver

resolver — решать (задачу, проблему). Глагол с чередованием гласной в корне, уровень B1. o → ue под ударением: resuelvo.

Настоящее (presente de indicativo)

yoresuelvo
túresuelves
él / ella / ustedresuelve
nosotrosresolvemos
vosotrosresolvéis
ellos / ustedesresuelven

Прошедшее законченное (pretérito indefinido)

túresolviste
él / ella / ustedresolvió
nosotrosresolvimos
vosotrosresolvisteis
ellos / ustedesresolvieron

Прошедшее длительное (pretérito imperfecto)

túresolvías
él / ella / ustedresolvía

vosotrosresolvíais
ellos / ustedesresolvían

nosotrosresolveremos
vosotrosresolveréis
ellos / ustedesresolverán

Условное (condicional simple)

túresolverías
él / ella / ustedresolvería
nosotrosresolveríamos

ellos / ustedesresolverían

Повелительное (imperativo afirmativo)
