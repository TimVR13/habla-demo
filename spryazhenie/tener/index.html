Спряжение глагола tener

tener — иметь. Неправильный глагол, уровень A1. yo: tengo; e → ie; прош.: tuve; буд.: tendré; повел.: ten.

Настоящее (presente de indicativo)

yotengo
tútienes
él / ella / ustedtiene
nosotrostenemos
vosotrostenéis
ellos / ustedestienen

Прошедшее законченное (pretérito indefinido)

yotuve
tútuviste
él / ella / ustedtuvo
nosotrostuvimos
vosotrostuvisteis
ellos / ustedestuvieron

Прошедшее длительное (pretérito imperfecto)

yotenía
tútenías
él / ella / ustedtenía
nosotrosteníamos
vosotrosteníais
ellos / ustedestenían

Будущее (futuro simple)

yotendré
tútendrás
él / ella / ustedtendrá
nosotrostendremos
vosotrostendréis
ellos / ustedestendrán

Условное (condicional simple)

yotendría
tútendrías
él / ella / ustedtendría
nosotrostendríamos
vosotrostendríais
ellos / ustedestendrían

Повелительное (imperativo afirmativo)

túten
ustedtenga
nosotrostengamos
vosotrostened
ustedestengan

Subjuntivo настоящее (presente de subjuntivo)

yotenga
tútengas
él / ella / ustedtenga
nosotrostengamos
vosotrostengáis
ellos / ustedestengan

Subjuntivo прошедшее (imperfecto de subjuntivo (-ra))

yotuviera
tútuvieras
él / ella / ustedtuviera
nosotrostuviéramos
vosotrostuvierais
ellos / ustedestuvieran
