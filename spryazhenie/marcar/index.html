Спряжение глагола marcar

marcar — отмечать; набирать (номер). Правильный глагол, уровень B1. c → qu перед e: marqué, marque.

Настоящее (presente de indicativo)

yomarco
túmarcas
él / ella / ustedmarca
nosotrosmarcamos
vosotrosmarcáis
ellos / ustedesmarcan

Прошедшее законченное (pretérito indefinido)

yomarqué
túmarcaste
él / ella / ustedmarcó
nosotrosmarcamos
vosotrosmarcasteis
ellos / ustedesmarcaron
