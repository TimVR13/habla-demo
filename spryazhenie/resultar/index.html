Спряжение глагола resultar

resultar — оказываться. Правильный глагол, уровень B1.

Настоящее (presente de indicativo)

yoresulto
túresultas
él / ella / ustedresulta
nosotrosresultamos
vosotrosresultáis
ellos / ustedesresultan

Прошедшее законченное (pretérito indefinido)

yoresulté
túresultaste
él / ella / ustedresultó
nosotrosresultamos
vosotrosresultasteis
ellos / ustedesresultaron

él / ella / ustedresultaba
nosotrosresultábamos
vosotrosresultabais
ellos / ustedesresultaban

túresultarás
él / ella / ustedresultará
nosotrosresultaremos
vosotrosresultaréis
ellos / ustedesresultarán

Условное (condicional simple)

yoresultaría
túresultarías
él / ella / ustedresultaría
nosotrosresultaríamos
vosotrosresultaríais
ellos / ustedesresultarían

Повелительное (imperativo afirmativo)

ustedresulte
nosotrosresultemos
vosotrosresultad
ustedesresulten

yoresulte

Примеры с глаголом resultar

No dijo nada que nos resultara útil.
Он не сказал ничего, что оказалось бы нам полезным.
