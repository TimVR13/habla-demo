Спряжение глагола proponer

proponer — предлагать (идею, план). Неправильный глагол, уровень B1. как poner: propongo, propuse, propondré; повел.: propón.

Настоящее (presente de indicativo)

yopropongo
túpropones
él / ella / ustedpropone
nosotrosproponemos
vosotrosproponéis
ellos / ustedesproponen

Прошедшее законченное (pretérito indefinido)

yopropuse
túpropusiste
él / ella / ustedpropuso
nosotrospropusimos
vosotrospropusisteis
ellos / ustedespropusieron

Прошедшее длительное (pretérito imperfecto)

yoproponía
túproponías
él / ella / ustedproponía
nosotrosproponíamos
vosotrosproponíais
ellos / ustedesproponían

Будущее (futuro simple)

yopropondré
túpropondrás
él / ella / ustedpropondrá
nosotrospropondremos
vosotrospropondréis
ellos / ustedespropondrán

Условное (condicional simple)

yopropondría
túpropondrías
él / ella / ustedpropondría
nosotrospropondríamos
vosotrospropondríais
ellos / ustedespropondrían

Повелительное (imperativo afirmativo)

túpropón
ustedproponga
nosotrospropongamos
vosotrosproponed
ustedespropongan

Subjuntivo настоящее (presente de subjuntivo)

yoproponga

él / ella / ustedproponga

ellos / ustedespropongan

Примеры с глаголом proponer

La semana que viene el gobierno propondrá nuevas medidas para el transporte.
На следующей неделе правительство предложит новые меры для транспорта.
Lo que propones viene a ser lo mismo que dijo Inés.
То, что ты предлагаешь, — по сути то же самое, что сказала Инес.
Ella siempre consigue lo que se propone.
Она всегда добивается того, что задумала.
