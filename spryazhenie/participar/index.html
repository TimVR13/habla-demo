Спряжение глагола participar

participar — участвовать. Правильный глагол, уровень B1.

Настоящее (presente de indicativo)

yoparticipo
túparticipas
él / ella / ustedparticipa
nosotrosparticipamos
vosotrosparticipáis
ellos / ustedesparticipan

Прошедшее законченное (pretérito indefinido)

túparticipaste
él / ella / ustedparticipó
nosotrosparticipamos
vosotrosparticipasteis
ellos / ustedesparticiparon

túparticipabas
él / ella / ustedparticipaba

ellos / ustedesparticiparán

Условное (condicional simple)

túparticiparías

ellos / ustedesparticiparían

Примеры с глаголом participar

Todos los alumnos participaron en la obra de teatro.
Все ученики участвовали в спектакле.
