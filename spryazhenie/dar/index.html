Спряжение глагола dar

dar — давать. Неправильный глагол, уровень A1. yo: doy; прош.: di, dio (как -er); subj.: dé.

Настоящее (presente de indicativo)

yodoy
túdas
él / ella / ustedda
nosotrosdamos
vosotrosdais
ellos / ustedesdan

Прошедшее законченное (pretérito indefinido)

yodi
túdiste
él / ella / usteddio
nosotrosdimos
vosotrosdisteis
ellos / ustedesdieron

Прошедшее длительное (pretérito imperfecto)

yodaba
túdabas
él / ella / usteddaba
nosotrosdábamos
vosotrosdabais
ellos / ustedesdaban

Будущее (futuro simple)

yodaré
túdarás
él / ella / usteddará
nosotrosdaremos
vosotrosdaréis
ellos / ustedesdarán

Условное (condicional simple)

yodaría
túdarías
él / ella / usteddaría
nosotrosdaríamos
vosotrosdaríais
ellos / ustedesdarían

Повелительное (imperativo afirmativo)

túda
usteddé
nosotrosdemos
vosotrosdad
ustedesden

Subjuntivo настоящее (presente de subjuntivo)

yodé
túdes
él / ella / usteddé
nosotrosdemos
vosotrosdeis
ellos / ustedesden

Subjuntivo прошедшее (imperfecto de subjuntivo (-ra))

yodiera
túdieras
él / ella / usteddiera
nosotrosdiéramos
vosotrosdierais
ellos / ustedesdieran
