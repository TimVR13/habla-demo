Спряжение глагола trabajar

trabajar — работать. Правильный глагол, уровень A1.

Настоящее (presente de indicativo)

yotrabajo
tútrabajas
él / ella / ustedtrabaja
nosotrostrabajamos
vosotrostrabajáis
ellos / ustedestrabajan

Прошедшее законченное (pretérito indefinido)

tútrabajaste
él / ella / ustedtrabajó
nosotrostrabajamos
vosotrostrabajasteis
ellos / ustedestrabajaron

Прошедшее длительное (pretérito imperfecto)

yotrabajaba
tútrabajabas
él / ella / ustedtrabajaba
nosotrostrabajábamos
vosotrostrabajabais
ellos / ustedestrabajaban

tútrabajarás
él / ella / ustedtrabajará
nosotrostrabajaremos
vosotrostrabajaréis
ellos / ustedestrabajarán

Условное (condicional simple)

tútrabajarías
él / ella / ustedtrabajaría
nosotrostrabajaríamos
vosotrostrabajaríais
ellos / ustedestrabajarían

ustedtrabaje
