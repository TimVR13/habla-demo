Спряжение глагола practicar

practicar — практиковать. Правильный глагол, уровень A2. c → qu перед e: practiqué, practique.

Настоящее (presente de indicativo)

yopractico
túpracticas
él / ella / ustedpractica
nosotrospracticamos
vosotrospracticáis
ellos / ustedespractican

Прошедшее законченное (pretérito indefinido)

yopractiqué
túpracticaste
él / ella / ustedpracticó
nosotrospracticamos
vosotrospracticasteis
ellos / ustedespracticaron

Прошедшее длительное (pretérito imperfecto)

túpracticabas
él / ella / ustedpracticaba
nosotrospracticábamos
vosotrospracticabais
ellos / ustedespracticaban

túpracticarás
él / ella / ustedpracticará
nosotrospracticaremos
vosotrospracticaréis
ellos / ustedespracticarán

túpracticarías

nosotrospracticaríamos
vosotrospracticaríais
ellos / ustedespracticarían

ustedpractique

Примеры с глаголом practicar

Le regalé un diccionario a Lucía para que practicara con el español.
Я подарил Лусии словарь, чтобы она занималась испанским.
Cuanto más practicas, más vas aprendiendo.
Чем больше практикуешься, тем больше узнаёшь.
Por más que practico, no me sale la tortilla de patatas.
Сколько я ни тренируюсь, картофельная тортилья у меня не получается.
