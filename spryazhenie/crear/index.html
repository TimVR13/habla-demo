Спряжение глагола crear

crear — создавать. Правильный глагол, уровень B1.

Настоящее (presente de indicativo)

yocreo
túcreas
él / ella / ustedcrea
nosotroscreamos
vosotroscreáis
ellos / ustedescrean

Прошедшее законченное (pretérito indefinido)

yocreé
túcreaste
él / ella / ustedcreó
nosotroscreamos
vosotroscreasteis
ellos / ustedescrearon

Прошедшее длительное (pretérito imperfecto)

yocreaba
túcreabas
él / ella / ustedcreaba
nosotroscreábamos
vosotroscreabais
ellos / ustedescreaban

Будущее (futuro simple)

yocrearé
túcrearás
él / ella / ustedcreará
nosotroscrearemos
vosotroscrearéis
ellos / ustedescrearán

Условное (condicional simple)

yocrearía
túcrearías
él / ella / ustedcrearía
nosotroscrearíamos
vosotroscrearíais
ellos / ustedescrearían

Повелительное (imperativo afirmativo)

túcrea
ustedcree
nosotroscreemos
vosotroscread
ustedescreen

Subjuntivo настоящее (presente de subjuntivo)

yocree
túcrees
él / ella / ustedcree
nosotroscreemos
vosotroscreéis

nosotroscreáramos

ellos / ustedescrearan
