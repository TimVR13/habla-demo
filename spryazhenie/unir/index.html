Спряжение глагола unir

unir — объединять, соединять. Правильный глагол, уровень B1.

Настоящее (presente de indicativo)

youno
túunes
él / ella / ustedune
nosotrosunimos
vosotrosunís
ellos / ustedesunen

Прошедшее законченное (pretérito indefinido)

youní
túuniste
él / ella / ustedunió
nosotrosunimos
vosotrosunisteis
ellos / ustedesunieron

Прошедшее длительное (pretérito imperfecto)

younía
túunías
él / ella / ustedunía
nosotrosuníamos
vosotrosuníais
ellos / ustedesunían

Будущее (futuro simple)

youniré
túunirás
él / ella / ustedunirá
nosotrosuniremos
vosotrosuniréis
ellos / ustedesunirán

Условное (condicional simple)

youniría
túunirías
él / ella / usteduniría
nosotrosuniríamos
vosotrosuniríais
ellos / ustedesunirían

Повелительное (imperativo afirmativo)

túune
usteduna
nosotrosunamos
vosotrosunid
ustedesunan
