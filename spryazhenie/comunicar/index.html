Спряжение глагола comunicar

comunicar — сообщать. Правильный глагол, уровень B1. c → qu перед e: comuniqué, comunique.

Настоящее (presente de indicativo)

yocomunico
túcomunicas
él / ella / ustedcomunica
nosotroscomunicamos
vosotroscomunicáis
ellos / ustedescomunican

Прошедшее законченное (pretérito indefinido)

túcomunicaste
él / ella / ustedcomunicó
nosotroscomunicamos
vosotroscomunicasteis
ellos / ustedescomunicaron

Прошедшее длительное (pretérito imperfecto)

túcomunicabas
él / ella / ustedcomunicaba
nosotroscomunicábamos
vosotroscomunicabais
ellos / ustedescomunicaban

vosotroscomunicaréis
ellos / ustedescomunicarán

Примеры с глаголом comunicar

En la reunión nos comunicaron que cambia el horario.
На собрании нам сообщили, что меняется расписание.
