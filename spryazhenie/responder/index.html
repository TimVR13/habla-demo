Спряжение глагола responder

responder — отвечать. Правильный глагол, уровень A2.

Настоящее (presente de indicativo)

yorespondo
túrespondes
él / ella / ustedresponde
nosotrosrespondemos
vosotrosrespondéis
ellos / ustedesresponden

Прошедшее законченное (pretérito indefinido)

yorespondí
túrespondiste
él / ella / ustedrespondió
nosotrosrespondimos
vosotrosrespondisteis
ellos / ustedesrespondieron

Прошедшее длительное (pretérito imperfecto)

yorespondía
túrespondías
él / ella / ustedrespondía
nosotrosrespondíamos
vosotrosrespondíais
ellos / ustedesrespondían

Будущее (futuro simple)

yoresponderé
túresponderás
él / ella / ustedresponderá
nosotrosresponderemos
vosotrosresponderéis
ellos / ustedesresponderán

Условное (condicional simple)

yorespondería
túresponderías
él / ella / ustedrespondería
nosotrosresponderíamos
vosotrosresponderíais
ellos / ustedesresponderían

Повелительное (imperativo afirmativo)

túresponde
ustedresponda
nosotrosrespondamos
vosotrosresponded
ustedesrespondan

Subjuntivo настоящее (presente de subjuntivo)

yoresponda
túrespondas
él / ella / ustedresponda
nosotrosrespondamos
vosotrosrespondáis
ellos / ustedesrespondan

Subjuntivo прошедшее (imperfecto de subjuntivo (-ra))

yorespondiera
túrespondieras
él / ella / ustedrespondiera
nosotrosrespondiéramos
vosotrosrespondierais
ellos / ustedesrespondieran

Примеры с глаголом responder

El jueves nosotros respondimos a todas las cartas de los clientes.
В четверг мы ответили на все письма клиентов.
El profesor repitió la pregunta tres veces, pero nadie respondió.
Преподаватель трижды повторил вопрос, но никто не ответил.
