Спряжение глагола entregar

entregar — вручать, сдавать. Правильный глагол, уровень B1. g → gu перед e: entregué, entregue.

Настоящее (presente de indicativo)

yoentrego
túentregas
él / ella / ustedentrega
nosotrosentregamos
vosotrosentregáis
ellos / ustedesentregan

Прошедшее законченное (pretérito indefinido)

yoentregué
túentregaste
él / ella / ustedentregó
nosotrosentregamos
vosotrosentregasteis
ellos / ustedesentregaron

Прошедшее длительное (pretérito imperfecto)

yoentregaba
túentregabas
él / ella / ustedentregaba
nosotrosentregábamos
vosotrosentregabais
ellos / ustedesentregaban

yoentregaré
túentregarás
él / ella / ustedentregará
nosotrosentregaremos
vosotrosentregaréis
ellos / ustedesentregarán

Условное (condicional simple)

yoentregaría
túentregarías
él / ella / ustedentregaría
nosotrosentregaríamos
vosotrosentregaríais
ellos / ustedesentregarían

Повелительное (imperativo afirmativo)

ustedentregue
nosotrosentreguemos
vosotrosentregad
ustedesentreguen

Примеры с глаголом entregar

Dudo que Rodrigo entregue el informe a tiempo.
Сомневаюсь, что Родриго вовремя сдаст отчёт.
Aunque el plazo ya había vencido cuando lo entregué, el profesor aceptó mi trabajo.
Хотя, когда я сдал работу, срок уже истёк, преподаватель её принял.
Mi jefa quería que termináramos el informe para el viernes, pero lo entregamos el lunes.
Начальница хотела, чтобы мы закончили отчёт к пятнице, но мы сдали его в понедельник.
