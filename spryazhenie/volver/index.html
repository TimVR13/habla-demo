Спряжение глагола volver

volver — возвращаться. Глагол с чередованием гласной в корне, уровень A1. o → ue под ударением.

Настоящее (presente de indicativo)

yovuelvo
túvuelves
él / ella / ustedvuelve
nosotrosvolvemos
vosotrosvolvéis
ellos / ustedesvuelven

Прошедшее законченное (pretérito indefinido)

yovolví
túvolviste
él / ella / ustedvolvió
nosotrosvolvimos
vosotrosvolvisteis
ellos / ustedesvolvieron

Прошедшее длительное (pretérito imperfecto)

túvolvías
él / ella / ustedvolvía
nosotrosvolvíamos
vosotrosvolvíais
ellos / ustedesvolvían

túvolverás

nosotrosvolveremos
vosotrosvolveréis
ellos / ustedesvolverán

Условное (condicional simple)

yovolvería
túvolverías
él / ella / ustedvolvería
nosotrosvolveríamos
vosotrosvolveríais
ellos / ustedesvolverían

Повелительное (imperativo afirmativo)

túvuelve
ustedvuelva
nosotrosvolvamos
vosotrosvolved
ustedesvuelvan

Subjuntivo настоящее (presente de subjuntivo)

nosotrosvolvamos
