Спряжение глагола explicar

explicar — объяснять. Правильный глагол, уровень A2. c → qu перед e: expliqué, explique.

Настоящее (presente de indicativo)

yoexplico
túexplicas
él / ella / ustedexplica
nosotrosexplicamos
vosotrosexplicáis
ellos / ustedesexplican

Прошедшее законченное (pretérito indefinido)

yoexpliqué
túexplicaste
él / ella / ustedexplicó
nosotrosexplicamos
vosotrosexplicasteis
ellos / ustedesexplicaron

Прошедшее длительное (pretérito imperfecto)

yoexplicaba
túexplicabas
él / ella / ustedexplicaba
nosotrosexplicábamos
vosotrosexplicabais
ellos / ustedesexplicaban

túexplicarás

nosotrosexplicaremos
vosotrosexplicaréis
ellos / ustedesexplicarán

Условное (condicional simple)

túexplicarías

ellos / ustedesexplicarían
