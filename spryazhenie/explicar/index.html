Спряжение глагола explicar

explicar — объяснять. Правильный глагол, уровень A2. c → qu перед e: expliqué, explique.

Настоящее (presente de indicativo)

yoexplico
túexplicas
él / ella / ustedexplica
nosotrosexplicamos
vosotrosexplicáis
ellos / ustedesexplican

Прошедшее законченное (pretérito indefinido)

yoexpliqué
túexplicaste
él / ella / ustedexplicó
nosotrosexplicamos
vosotrosexplicasteis
ellos / ustedesexplicaron

Прошедшее длительное (pretérito imperfecto)

yoexplicaba
túexplicabas
él / ella / ustedexplicaba
nosotrosexplicábamos
vosotrosexplicabais
ellos / ustedesexplicaban

Будущее (futuro simple)

yoexplicaré
túexplicarás
él / ella / ustedexplicará
nosotrosexplicaremos
vosotrosexplicaréis
ellos / ustedesexplicarán

Условное (condicional simple)

yoexplicaría
túexplicarías
él / ella / ustedexplicaría
nosotrosexplicaríamos
vosotrosexplicaríais
ellos / ustedesexplicarían

Повелительное (imperativo afirmativo)

túexplica
ustedexplique
nosotrosexpliquemos
vosotrosexplicad
ustedesexpliquen

Subjuntivo настоящее (presente de subjuntivo)

yoexplique
túexpliques
él / ella / ustedexplique
nosotrosexpliquemos
vosotrosexpliquéis
ellos / ustedesexpliquen

él / ella / ustedexplicara
nosotrosexplicáramos

ellos / ustedesexplicaran
