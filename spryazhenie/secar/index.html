Спряжение глагола secar

secar — сушить. Правильный глагол, уровень A2. c → qu перед e: sequé, seque.

Настоящее (presente de indicativo)

yoseco
túsecas
él / ella / ustedseca
nosotrossecamos
vosotrossecáis
ellos / ustedessecan
